#Framework
## Definição

- Framework Web para construção de APIs com python;
- Precisa de tipagem.
## Pontos Positivos
###### 1. Alto Desempenho
→ Comparável ao Node.js e superior ao Flask
###### 2. Geração de Documentação Automática
→ Suporta OpenAI para documentação
###### 3. Validação de Dados e Serialização 

→ Usa **Pydantic** para validação de dados e serialização automática.

> Serialização: "Achatar" o seu objeto para que ele vire uma sequência de bytes ou uma string.

###### 4. Facilidade de Uso
→ Aprender a começar a usar o FastAPI é geralmente considerado simples

###### 5. Suporte a async/await
→ Suporte nativo para operações assíncronas, o que é ótimo para lidar com operações de IO

## Pontos Negativos

1. Comunidade menor
2. Maturidade
3. Complexidade em Projetos Grandes
